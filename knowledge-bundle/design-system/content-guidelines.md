# UI Copy Guidelines

## Copywriting
- Judul halaman: sentence case ("Riwayat Transaksi"); tombol: kata kerja singkat ("Simpan", "Batal", "Terapkan", "Lihat Semua").
- Eyebrow section: UPPERCASE ("UTAMA", "ATUR").
- Uang: selalu dengan mata uang + format konsisten (produk Indonesia: `Rp 24.000.000`); delta sebagai Badge berwarna ("+5%", "-3%").
- Field: Label + `*` wajib / sublabel "(Opsional)"; hint satu kalimat.
